# Stock AI — ระบบวิเคราะห์หุ้นไทย/อเมริกา อัตโนมัติ

ดึงราคาหุ้น → เก็บลงฐานข้อมูล (ความจำ) → วิเคราะห์ด้วย Gemini → สรุปส่งเข้า Discord

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `database.py` | ระบบความจำ (SQLite) |
| `fetch_data.py` | ดึงราคาหุ้นไทย+อเมริกา |
| `fetch_fear_greed.py` | ดึง CNN Fear & Greed Index + สัญญาณซื้อขายแบบ Contrarian |
| `analyze.py` | เรียก Gemini API วิเคราะห์ |
| `notify_discord.py` | ส่งสรุปเข้า Discord |
| `main.py` | ไฟล์หลัก รันตัวนี้ไฟล์เดียว |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. ติดตั้ง Python
ถ้ายังไม่มี ดาวน์โหลดจาก https://www.python.org/downloads/ (เลือกติ๊ก "Add to PATH" ตอนติดตั้ง)

### 2. ติดตั้งไลบรารีที่ต้องใช้
เปิด Command Prompt / Terminal ไปที่โฟลเดอร์นี้ แล้วรัน:
```
pip install -r requirements.txt
```

### 3. ขอ Gemini API Key (ฟรี ไม่ต้องผูกบัตร)
1. ไปที่ https://aistudio.google.com/apikey
2. ล็อกอินด้วยบัญชี Google
3. กด **Create API key** แล้วคัดลอกค่าที่ได้
4. รุ่น `gemini-3-flash` ที่ใช้ในโปรเจกต์นี้มี Free Tier ให้ใช้ฟรีในโควตาจำกัด (พอเหลือเฟือสำหรับรันวันละ 1 ครั้ง) — ถ้าใช้เกินโควตาฟรี ค่อยพิจารณาเปิดบิลลิ่งทีหลัง

### 4. ตั้งค่า Discord Webhook
1. เปิด Discord ไปที่ช่อง (channel) ที่ต้องการให้ส่งรายงาน
2. คลิกฟันเฟือง (แก้ไขช่อง) → Integrations → Webhooks → New Webhook
3. ตั้งชื่อ แล้วกด **Copy Webhook URL**

### 5. สร้างไฟล์ `.env`
คัดลอกไฟล์ `.env.example` เป็นไฟล์ชื่อ `.env` แล้วใส่ค่าจริงของคุณ:
```
GEMINI_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxx
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/xxxxxxxxxxxx
```

## โหมดสองทาง — สั่งงานผ่าน Discord ได้ทันที (ไฟล์ `discord_bot.py`)

นอกจากรายงานอัตโนมัติ (`main.py`) ยังมีบอทที่รับคำสั่งสดๆ ในดิสคอร์ดได้ เช่น พิมพ์ `/stock AAPL` แล้วบอทวิเคราะห์ตอบกลับทันที

**ข้อแตกต่างสำคัญ:** `main.py` รันครั้งเดียวจบ (เหมาะตั้งเวลา) ส่วน `discord_bot.py` ต้อง**รันค้างไว้ตลอดเวลา**เพื่อรอฟังคำสั่ง ปิดหน้าต่างเมื่อไหร่บอทออฟไลน์ทันที

### วิธีสร้างบอท (ทำครั้งเดียว)

1. ไปที่ https://discord.com/developers/applications → **New Application** → ตั้งชื่ออะไรก็ได้
2. เมนูซ้าย **Bot** → กด **Reset Token** (หรือ Copy ถ้ามีอยู่แล้ว) → คัดลอกค่า Token เก็บไว้
3. ยังอยู่หน้า Bot: เปิด **Public Bot** ไว้ (ถ้าจะใช้คนเดียวปิดก็ได้)
4. เมนูซ้าย **OAuth2 → URL Generator**:
   - Scopes: ติ๊ก `bot` และ `applications.commands`
   - Bot Permissions: ติ๊ก `Send Messages`, `Embed Links`, `Use Slash Commands`
   - คัดลอก URL ด้านล่างที่ระบบสร้างให้ เปิดในเบราว์เซอร์ แล้วเลือกเซิร์ฟเวอร์ที่จะเชิญบอทเข้าไป
5. เอา Token จากข้อ 2 ไปใส่ในไฟล์ `.env`:
```
DISCORD_BOT_TOKEN=ค่าที่คัดลอกมา
```

### วิธีใช้งาน

```
python discord_bot.py
```

รอจนเห็นข้อความ `✅ บอทออนไลน์แล้ว...` แล้วไปที่ช่อง Discord ที่เชิญบอทเข้าไป พิมพ์ `/` จะเห็นเมนูคำสั่งขึ้นมา:
- `/stock ticker:AAPL` — สรุปหุ้นตัวเดียว
- `/marketupdate` — สรุปตลาดรวมทุกตัวทันที

⚠️ คำสั่ง `/` อาจใช้เวลา 1-2 นาทีถึงจะขึ้นในเมนูดิสคอร์ดครั้งแรกที่รัน (ระบบ sync คำสั่งของ Discord เอง)

### เกี่ยวกับการรันค้างไว้ 24 ชม.

ตอนทดสอบ รันบนโน้ตบุ๊กแล้วเปิดหน้าต่างทิ้งไว้ก็พอ แต่ถ้าอยากให้บอทออนไลน์ตลอดโดยไม่ต้องเปิดเครื่อง ต้องเอาไปรันบนเซิร์ฟเวอร์ที่เปิดค้าง 24 ชม. (ต่างจาก GitHub Actions ที่ใช้กับ `main.py` เพราะบอทต้องเปิดการเชื่อมต่อค้างไว้ ไม่ใช่รันแล้วจบ) — ถ้าสนใจบอกได้ ผมช่วยแนะนำตัวเลือกฟรี/ราคาถูกให้ได้

## Fear & Greed Index และสัญญาณซื้อขาย

ระบบดึงค่า CNN Fear & Greed Index มาให้อัตโนมัติทุกครั้งที่รัน พร้อมแบ่งโซนตามเกณฑ์มาตรฐาน:

| ช่วงค่า | โซน | ความหมาย (แนว Contrarian) |
|---|---|---|
| 0-25 | Extreme Fear | 🟢 โซนซื้อ — ตลาดตื่นตระหนก อาจเป็นโอกาสเข้าสะสม |
| 26-45 | Fear | 🟡 ยังไม่ถึงจุดสุดขั้ว |
| 46-55 | Neutral | ⚪ ตลาดยังไม่มีอารมณ์ชัดเจน |
| 56-75 | Greed | 🟡 เริ่มร้อนแรง |
| 76-100 | Extreme Greed | 🔴 โซนขาย/ทำกำไร — ตลาดโลภสุดขั้ว เสี่ยงฟองสบู่ |

ค่านี้จะถูกส่งเข้า Discord เป็นฟิลด์แยกให้เห็นชัด และถูกส่งให้ Gemini ใช้ประกอบการวิเคราะห์ด้วย พร้อมเก็บประวัติย้อนหลังไว้เทียบแนวโน้มในการรันครั้งถัดไป

⚠️ **นี่คือกฎเกณฑ์ตายตัว (rule-based) ไม่ใช่คำแนะนำการลงทุน** เป็นเพียงหนึ่งในหลายอินดิเคเตอร์ที่นักลงทุนบางกลุ่มใช้ประกอบการตัดสินใจเท่านั้น

## รายงานสรุปเพิ่มเติม — รายสัปดาห์ / รายเดือน / Top 10 (แยกจากรายงานรายวัน)

รายงานรายวันเดิม (ที่ส่งทุก 15 นาทีตอนตลาดเปิดผ่าน `run_paper_trading.py`) **ไม่มีการเปลี่ยนแปลงใดๆ** ระบบใหม่นี้เป็นชุดรายงานแยกต่างหาก:

| คำสั่ง (ผ่านบอท) | สคริปต์ (รันเอง) | เนื้อหา |
|---|---|---|
| `/weeklyreport` | `python send_periodic_reports.py weekly` | สรุปผลย้อนหลัง 7 วัน |
| `/monthlyreport` | `python send_periodic_reports.py monthly` | สรุปผลย้อนหลัง 30 วัน |
| `/top10report` | `python send_periodic_reports.py top10` | อันดับหุ้นทำกำไรสะสมสูงสุด 10 อันดับ |
| — | `python send_periodic_reports.py all` | ส่งทั้ง 3 ชุดรวดเดียว (คนละการ์ด) |

ทดสอบดูหน้าตาก่อนได้ทันทีด้วยข้อมูลตัวอย่าง (ไม่ต้องรอมีออเดอร์จริงสะสม):
```
python test_periodic_reports.py
```

⚠️ ตัวเลขกำไร/ขาดทุนเป็นผลรวมแบบบวกตรงๆ ต่อไม้ (ไม่ได้คิดทบต้น) ใช้เปรียบเทียบภาพรวมกลยุทธ์เท่านั้น

**แนะนำ:** พอย้ายไปตั้งเวลารันอัตโนมัติ (GitHub Actions) ในอนาคต ตั้ง `send_periodic_reports.py weekly` ให้รันทุกวันศุกร์หลังตลาดปิด และ `monthly` ให้รันวันสุดท้ายของเดือนได้เลย

## Day Trade Simulator (Paper Trading) — ไฟล์ `run_paper_trading.py`

⚠️ **นี่คือการจำลองเท่านั้น ไม่มีการซื้อขายเงินจริงเกิดขึ้น ไม่เชื่อมต่อโบรกเกอร์ใดๆ ทั้งสิ้น** เป็นเครื่องมือช่วยทดสอบแนวคิดกลยุทธ์ ไม่ใช่คำแนะนำการลงทุน

### วิธีทำงาน (เวอร์ชัน 1)

- สแกนหุ้น 25 ตัวใน `watchlist.py` ทุก 15 นาทีระหว่างตลาดอเมริกาเปิด (9:30-16:00 เวลานิวยอร์ก จันทร์-ศุกร์ — ใช้เวลานิวยอร์กจริง ไม่ใช่เวลาไทย)
- **กลยุทธ์:** Breakout + Volume + RSI — เข้าออเดอร์เมื่อราคาทะลุแนวต้าน R1 (จาก Pivot Point) พร้อมวอลุ่มพุ่งเกิน 1.3 เท่าค่าเฉลี่ย 20 วัน และ RSI อยู่ที่ 50-75 (ขาขึ้นแต่ยังไม่ overbought สุดขั้ว)
- เปิดออเดอร์จำลองพร้อมกันสูงสุด 5 ตัว เลือกจากคะแนน (score) สูงสุดก่อน
- **ปิดออเดอร์อัตโนมัติ** เมื่อราคาชน TP1 (กำไร) หรือ SL1 (ขาดทุน) หรือถูกบังคับปิดตอนใกล้ตลาดปิด (กติกา Day Trade ห้ามถือข้ามวัน)
- ส่งรายงานตาราง (ออเดอร์เปิดอยู่ + ปิดแล้ววันนี้) เข้า Discord ทุกรอบ

**ข้อจำกัดที่ควรรู้ (V1):** ปิดเต็มไม้ที่ TP1/SL1 เท่านั้น — TP2/TP3/SL2/SL3 แสดงไว้ในฐานข้อมูลเป็นข้อมูลอ้างอิง ยังไม่มีการปิดออเดอร์บางส่วน (partial exit) แบบหลายขั้น จะพัฒนาต่อในเวอร์ชันถัดไปได้

### วิธีใช้งาน

```
python run_paper_trading.py
```

ต้องรันค้างไว้ตลอดช่วงตลาดเปิด (คล้าย `discord_bot.py`) กด `Ctrl+C` เพื่อหยุด นอกเวลาตลาดเปิดโปรแกรมจะข้ามรอบไปเฉยๆ ไม่ error

### ปรับแต่งกลยุทธ์

แก้ค่าตัวแปรด้านบนของ `day_trade_engine.py`:
- `MIN_VOLUME_RATIO` — ความไวต่อวอลุ่ม (ยิ่งสูงยิ่งเข้มงวด)
- `RSI_MIN` / `RSI_MAX` — กรอบ RSI ที่ยอมรับ
- `MAX_CONCURRENT_TRADES` — จำนวนออเดอร์เปิดพร้อมกันสูงสุด

แก้รายชื่อหุ้นได้ที่ `watchlist.py`

## การจัดการเวอร์ชัน (Git) — กันพังแล้วย้อนกลับได้

แนะนำให้ตั้ง Git ในโฟลเดอร์นี้ก่อนแก้ไขอะไรเพิ่ม เพื่อให้ย้อนกลับได้เสมอถ้าเวอร์ชันใหม่มีปัญหา:

```
git init
git add .
git commit -m "เวอร์ชันที่ใช้งานได้ - ก่อนเพิ่ม Day Trade Simulator"
```

ทุกครั้งที่แก้ไฟล์แล้วทดสอบผ่าน ให้ commit เก็บไว้อีกครั้ง:
```
git add .
git commit -m "อธิบายสั้นๆ ว่าแก้อะไร"
```

ถ้าเวอร์ชันล่าสุดพังหรือไม่ชอบผลลัพธ์ ย้อนกลับไปคอมมิตก่อนหน้าได้ด้วย:
```
git log --oneline          (ดูประวัติ commit ทั้งหมด พร้อมรหัสย่อ)
git checkout <รหัสคอมมิต> -- .   (ดึงไฟล์ทั้งหมดกลับไปเป็นเวอร์ชันนั้น)
```

## ขั้นต่อไป (เมื่อทดสอบแล้วโอเค)

1. รันด้วยมือทุกวันสัก 3-5 วันแรก ดูว่าผลวิเคราะห์มีประโยชน์จริง
2. ตั้งเวลารันอัตโนมัติทุกเช้า — แนะนำใช้ **GitHub Actions** (ฟรี ไม่ต้องเปิดเครื่องทิ้งไว้)
   - ผมช่วยตั้งค่าให้ได้เมื่อพร้อม แค่บอกได้เลย
3. ต่อยอด: เพิ่มหุ้น, เพิ่มข่าว, ปรับ prompt ให้วิเคราะห์ลึกขึ้น, เก็บสถิติความแม่นยำ
